### DOM and Events

</div>

## 📜 The Story

The Hall of Elements contains a magical bell that warns Codoria whenever danger approaches. The Dark Bug has silenced it by damaging the connection between the royal button and its message.

Restore the DOM spell and make the bell ring again!

| Detail | Information |
|---|---|
| ⏳ Time | 8 minutes |
| 👥 Formation | Team of 3 |
| 🐛 Bugs | 3 |
| 🧠 Skills | DOM selection, events and text updates |

## 🎯 Your Mission

Open `index.html` in the browser and inspect `app.js`. Repair the three bugs.

When the **Ring the Royal Bell** button is clicked, the page must display:

```text
🔔 The Royal Bell is ringing! Codoria has been warned!
```

## ✅ Victory Conditions

- [ ] The message element is selected correctly
- [ ] The function runs only after the button is clicked
- [ ] The message text is updated correctly
- [ ] No errors appear in the browser console
- [ ] Every team member can explain one repair

## ⭐ Bonus Quest

After the bell rings:

- Change the button text to `Bell Activated!`
- Disable the button so it cannot be clicked again

Completing the bonus quest earns **5 additional Kingdom Points**.
