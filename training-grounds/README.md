## 📜 The Story

Before entering battle, every Software Knight must pass through the Training Grounds. Unfortunately, the Dark Bug has damaged the Royal Supply System. New supplies cannot be added, and the quartermaster cannot count the inventory.

Repair the system before the knights leave for battle!

| Detail | Information |
|---|---|
| ⏳ Time | 8 minutes |
| 👥 Formation | Team of 3 |
| 🐛 Bugs | 3 |
| 🧠 Skills | Arrays, functions, arguments and return values |

## 🎯 Your Mission

Open `app.js` and repair the three bugs.

Run the code with:

```bash
node app.js
```

The completed program must display:

```text
⚔️ The royal inventory contains 4 supplies.
```

## ✅ Victory Conditions

- [ ] `Map` is added to the array
- [ ] The function returns the number of supplies
- [ ] The correct function is called
- [ ] The console displays `4 supplies`
- [ ] Every team member can explain one repair

## ⭐ Bonus Quest

Use a loop to display every supply like this:

```text
📦 Sword
📦 Shield
📦 Potion
📦 Map
```

Completing the bonus quest earns **5 additional Kingdom Points**.
